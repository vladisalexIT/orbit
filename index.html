Новая задача

С оценкой времени — обратный отсчёт. Без оценки — секундомер. Длительность подзадач входит в бюджет родителя.

Дедлайн отсчитывается по календарю, даже когда таймер на паузе.

Пространство для ясности

Три уровня — достаточно

Задача → подзадача → конкретный шаг. Стрелка раскрывает ветку, «+» добавляет следующий уровень, карандаш открывает редактирование. Галочка завершает задачу вместе со всеми её подзадачами.

Один фокус за раз

Нажмите ▶, чтобы перейти в статус «В процессе». Другой работающий таймер остановится. Пауза сохраняет результат. Когда выделенное время закончится, появится уведомление и статус «Время вышло» — завершение вы подтверждаете сами. В редакторе можно увеличить время или сбросить таймер отдельной кнопкой в карточке.

Честный бюджет: 16 часов

Для каждой ветки берётся большее: оценка родителя или сумма бюджетов его подзадач. Например, проект 2 часа и два шага по 30 минут занимают 2 часа, а не 3. Задачи без оценки занимают 0 часов: это не запрет работать, а напоминание оценить план. Выполненные задачи остаются в бюджете дня.

Сегодня, позже и новый день

Задачи на сегодня привязаны к дате создания плана. Незавершённые задачи прошлых дней находятся во вкладке «Позже» с отметкой «Просрочен план». Перенесите их на сегодня в редакторе. Автоматического переноса нет, чтобы новый день не переполнялся.

Прогресс без двойного счёта

Считаются конечные шаги — задачи без подзадач. Родителя можно завершить вручную или он завершится автоматически, когда готовы все его подзадачи. Дедлайн родителя показывается независимо от рабочего таймера.

Данные остаются у вас

Сохранение — в браузере на этом устройстве. Между телефоном и компьютером синхронизации нет. В настройках есть экспорт и импорт JSON. Очистка данных браузера удалит задачи, если нет резервной копии. Закрытая вкладка не запускает код, но время работающего таймера учитывается при следующем открытии.

Данные и настройки

Задачи сохраняются локально. Для переноса на другое устройство скачайте резервную копию и имортируйте её там.

Файл приложения

Скачайте HTML, переименуйте его в index.html и загрузите в репозиторий GitHub Pages. Внешних библиотек и подключений нет. Задачи не включаются в HTML — их переносите отдельно через JSON.

Начать с чистого листа

Первое открытие содержит примеры. Можно удалить их все и создать собственный план.
